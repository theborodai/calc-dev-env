Replies to PO/CISO in GitHub issues start directly with the substance (e.g. "Загальний підхід погоджуємо: …"), without a thank-you opener.

**Why:** 2026-11-05 the user said "Дякуємо" first is template-like and unnecessary.

**How to apply:** all comments/drafts written on the user's behalf. Related: [[no-pending-promises-in-issues]].
