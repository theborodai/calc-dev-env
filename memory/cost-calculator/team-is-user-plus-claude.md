"Ми працюємо вдвох" means the user + Claude, not two human developers. Both work on the same task at the same moment: the user steers, asks questions, reviews when needed; Claude writes the code.

**Why:** on 2026-10-16 I estimated a calendar with a 1.6× two-developer parallelism factor; the user corrected that this is not two developers.

**How to apply:** in effort/calendar estimates, no parallelism between tasks; the bottleneck is the user's attention (steering, decisions, review), and calendar ≈ the user's working weeks plus waiting on PO/factory/access. Related: [[github-accounts-and-po]].
